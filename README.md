# rnaseq-neurodegeneration
RNA-seq differential expression pipeline for neurodegenerative disease research, demonstrated on public GEO data (Alzheimer's, GSE104704)

# neurodegeneration-rnaseq-pipeline

> **Note:** This repository demonstrates a differential expression pipeline 
> originally developed for a manuscript currently under peer review. 
> To showcase the methodology without disclosing unpublished data, 
> the pipeline has been adapted to run on a public dataset (GSE104704, 
> Alzheimer's disease, GEO). Once the associated manuscript is published, 
> a citation and link will be added here.

## Overview
RNA-seq differential expression pipeline (Old vs. AD, lateral temporal lobe), 
adapted to run on public GEO data. Originally developed for neurodegeneration 
research; demonstrated here using an Alzheimer's disease dataset.

**Sample subset**: 3 biological replicates per condition were selected from 
GSE104704, pairwise matched by age, post-mortem interval, and RIN to minimize 
confounding, and restricted to male donors given the small sample size. 
See [METHODS.md](./METHODS.md) for full selection rationale.

## Repository structure
├── R/ # reusable functions
├── scripts/ # analysis pipeline, run in numbered order
├── data/ # metadata + instructions for reproducing data download
├── figures/ # output plots generated by the pipeline
├── shiny_app/ # interactive Shiny app (self-contained)


VER ## Pipeline
1. `scripts/01_download_data.R` — retrieve counts via recount3
2. `scripts/02_qc.R` — DESeq2 object, filtering, normalization, PCA, shrinkage
3. `scripts/03_volcano_plot.R` — results table, gene symbol mapping, volcano plot
4. `scripts/04_heatmap.R` — heatmap of significant genes
5. `scripts/05_biomarker_candidates.R` — exploratory biomarker candidate analysis
6. `scripts/06_literature_check.R` — GWAS Catalog cross-reference for candidates
7. `scripts/07_GO_enrichment.R` — GO over-representation analysis
